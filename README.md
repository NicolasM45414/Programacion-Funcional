# 💻 Proyecto – Programación Funcional en Java

### 📚 Trabajo Práctico  

Este proyecto demuestra el uso de **programación funcional en Java**, utilizando expresiones lambda, *streams*, funciones puras y manejo de colecciones de forma declarativa.  
El objetivo es mostrar cómo aplicar conceptos funcionales dentro del paradigma orientado a objetos de Java.

## 🧠 Nuevas Funcionalidades Incorporadas

- **Uso de Streams encadenados:** pipeline de operaciones para transformar y reducir colecciones.
- **Expresiones Lambda:** permiten escribir funciones compactas y legibles.
- **Operaciones terminales y de reducción:** `forEach`, `count`, `sum`, `average`, `max`, `min`.
- **Agrupamientos avanzados:** `groupingBy()` con collectors anidados (como `counting()` y `summingDouble()`).
- **Programación inmutable:** se evita modificar colecciones originales durante el procesamiento.

---

## 🚀 Resultados y Conclusiones

El proyecto demuestra cómo la **programación funcional en Java** simplifica el procesamiento de datos y reduce la complejidad del código.  
Mediante el uso de **Streams y Lambdas**, se logró:

- Mayor legibilidad y expresividad en las operaciones.  
- Menor cantidad de líneas de código.  
- Código más seguro ante errores por mutación.  
- Fácil generación de reportes, promedios y agrupaciones.
